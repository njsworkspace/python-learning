# Personal Finance Calculator


โปรแกรมคำนวณสรุปรายรับและค่าใช้จ่ายรายเดือน พร้อมแสดงสัดส่วนค่าใช้จ่ายแต่ละหมวดและเงินออมเมื่อเทียบกับรายรับ


## ข้อมูลที่ต้องกรอก


โปรแกรมจะรับข้อมูลต่อไปนี้เป็นจำนวนเงินรายเดือน:



- รายรับ

- ค่าอาหาร

- ค่าเช่า

- ค่าสาธารณูปโภค

- ค่าเดินทาง

- เงินออม



## ผลลัพธ์


โปรแกรมแสดงรายรับรวม ค่าใช้จ่ายรวม รายรับสุทธิหลังหักค่าใช้จ่ายและเงินออม รวมถึงสัดส่วนของค่าอาหาร ค่าเช่า ค่าสาธารณูปโภค ค่าเดินทาง และเงินออมต่อรายรับ โดยแสดงจำนวนเงินเป็นดอลลาร์สหรัฐ (USD)


สูตรที่ใช้:



- ค่าใช้จ่ายรวม = ค่าอาหาร + ค่าเช่า + ค่าสาธารณูปโภค + ค่าเดินทาง

- รายรับสุทธิ = รายรับ − ค่าใช้จ่ายรวม − เงินออม

- สัดส่วนของแต่ละหมวด = จำนวนเงินในหมวด ÷ รายรับ



## วิธีใช้งาน



1. บันทึกโค้ดเป็นไฟล์ Python เช่น `personal-finance-calculator.py`

2. เปิดเทอร์มินัลในโฟลเดอร์ที่บันทึกไฟล์

3. เรียกใช้:


Bash






```
python personal-finance-calculator.py

```







หากระบบใช้คำสั่ง `python3` ให้เรียก `python3 personal-finance-calculator.py` แทน

4. กรอกจำนวนเงินเมื่อโปรแกรมถาม



ต้องกรอกรายรับมากกว่า 0 เพื่อให้คำนวณสัดส่วนได้ และควรกรอกตัวเลขที่ไม่ติดลบ
